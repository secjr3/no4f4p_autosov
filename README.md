##AutoSov
## - OQUE É?
 É um projecto inovador e ambicioso feito pra ajudar a tomar controle de comportamentos de vicíos impulsivos(como o vicio em conteúdo adulto).

## - DEMO
Acesse aqui -> https://secjr3.github.io/no4f4p_autosov/

## - COMO FUNCIONA?
o WebApp é simples, ele é como um companheiro coach de bolso. o app monitora, regista, avalia recaídas.
É offline e Mobile first, usa o localstorage do navegador, fazendo-o funcionar sem internet.

no momento o App conta com sistema de login, então é só pegar e usar. totalmente gratís.
